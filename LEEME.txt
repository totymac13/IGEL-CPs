TOTY PLANNER - VERSION CON SINCRONIZACION SUPABASE

Contenido:
- index.html, app.js, style.css: aplicación y panel de sincronización privada.
- sw.js: caché actualizada para cargar la nueva versión.
- manifest e iconos.

CONFIGURAR SUPABASE
1. En Supabase, abre Settings > API Keys y copia la Project URL y la Publishable key (sb_publishable_...). Nunca uses ni publiques sb_secret_ o service_role.
2. Abre TOTY Planner y despliega “Sincronización privada”.
3. Introduce la URL y la clave pública y pulsa “Guardar configuración en este navegador”. La configuración se guarda en localStorage de ese dispositivo.
4. Introduce correo y contraseña. Usa “Crear cuenta” si aún no tienes usuario; si la confirmación por email está activada, confirma el correo y luego inicia sesión.
5. En el primer dispositivo con los datos que quieres conservar, pulsa “Subir datos de este dispositivo” y confirma. Esto crea/actualiza tu fila privada en public.planner_data.
6. En el otro dispositivo, configura la misma URL y clave, inicia sesión con la misma cuenta y pulsa “Descargar datos de la nube”.
7. En cada dispositivo, tras elegir la fuente de datos correcta una vez, las siguientes ediciones se suben automáticamente tras una breve pausa. Para traer cambios hechos en el otro dispositivo, pulsa “Descargar datos de la nube” y confirma; esta versión no fusiona cambios simultáneos.

SEGURIDAD Y LIMITACIONES
- La tabla public.planner_data debe tener RLS activado y las políticas select/insert/update limitadas a auth.uid() = user_id. Ejecutar el SQL de configuración proporcionado en la guía.
- Solo se usa la Publishable key en el navegador; jamás incluir secret/service_role.
- Descargar de la nube reemplaza los datos locales, y subir reemplaza la fila de la nube. Haz una copia JSON antes y confirma con cuidado.
- La sincronización es por documento completo: no fusiona cambios simultáneos y no tiene sincronización en tiempo real; usa “Descargar datos de la nube” para traer cambios del otro dispositivo.
- Si se cambia la estructura de la tabla, políticas o autenticación, puede requerir ajustes.
- Esta versión debe probarse con datos de prueba antes de confiarle información importante.
