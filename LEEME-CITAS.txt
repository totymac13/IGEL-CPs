TOTY Planner - Citas

Esta versión añade gestión de citas y conserva las funciones de tareas, hábitos, balance y copias de seguridad de la versión Premium para iPhone.

Archivos incluidos:
- index.html
- app.js
- style.css
- sw.js

Instalación en GitHub Pages:
1. Descarga una copia de seguridad JSON desde tu versión actual, si puedes.
2. Descomprime el ZIP.
3. Sustituye los cuatro archivos anteriores en la raíz del repositorio (no subas una carpeta contenedora).
4. Haz Commit changes y espera a que GitHub Pages publique los cambios.
5. Recarga la página. Si usas la PWA instalada, ciérrala y vuelve a abrirla.

Citas:
- Nombre, fecha, hora de inicio y fin, lugar, notas y aviso previo configurable.
- Estados: pendiente, realizada o cancelada.
- Se pueden eliminar citas.
- Los datos se incluyen en la copia JSON exportada y restaurada.

Avisos:
Los recordatorios se comprueban mientras la agenda está abierta. El navegador puede mostrar notificaciones si el usuario concede permiso. En iPhone/iOS, las notificaciones y tareas en segundo plano pueden estar limitadas cuando la aplicación está cerrada; no se garantiza un aviso puntual con la PWA cerrada.

Seguridad:
No borres los datos del navegador para instalar esta versión. La clave de almacenamiento se mantiene compatible. Descarga y guarda también una copia JSON fuera del dispositivo antes de actualizar.
